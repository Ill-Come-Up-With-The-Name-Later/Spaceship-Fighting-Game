# Spaceship Fighting Game

I really need to come up with a new title for this.

In this game, you control a basic spaceship and have to fight other
spaceships to survive.

There is no backstory, and currently there is no ending.

## Inspirations

This game is inspired almost entirely by Star Trek: Voyager, specifically, Season 7,
Episode 15, "The Void." Overall, the game is simply inspired by science fiction and
space.
